## Craft

This entry follows the winner structure from the previous day's winning paper (news-22) and the craft fixes from news-23 v5: bigger body text everywhere, numbered text cards instead of photo thumbnails, no map at all (the space goes to text), a colour-coded region legend, a clear hierarchy, zero AI-drawn text, zero garbled words, zero internal number contradictions.

## How it was made

Dense text is typeset in HTML/CSS and captured with a headless-Chromium screenshot, so every word is typed, never drawn by an image model. The three hero illustrations are AI-generated photographs (no text in the images).
